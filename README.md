# My Data Analytics Portfolio

A single-page portfolio site — same structure as most professional data
portfolios: Hero → About → Experience → Education → Projects → Skills → Contact.

## Files
- `index.html` — all content lives here
- `style.css` — all styling/colors/fonts
- `script.js` — mobile menu, scroll progress bar, contact form handler
- `assets/` — put `profile.jpg` here
- `resume.pdf` — put your resume in the root folder (same level as index.html)

## How to edit content
Open `index.html` in any text editor and replace:
- "Your Name" → your actual name (appears ~6 times)
- Email, phone, LinkedIn, GitHub links
- About paragraph
- Experience / Education entries
- Project cards (title, description, tech chips, GitHub link)
- Skills lists

Colors and fonts live at the top of `style.css` under `:root`.
